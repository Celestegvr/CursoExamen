Flexbox en tiempo récord

        
Una forma de maquetar con cajas flexibles. Un layout con Flexbox siempre tiene una dimensión: horizontal (fila) o vertical (columna).

      

    


    
paso 1 Prepara la práctica

    
Crea la carpeta repaso-flexbox con index.html y styles.css. Dentro del body pon una section con la clase flex-container y varias cajas. Para activar Flexbox basta con display: flex en el contenedor: ya no hacen falta float ni clearfix.

    

      

      

    


    
paso 2 Juega con las propiedades

    
Arriba, las propiedades del contenedor; abajo, las de los hijos (C1, C2 y C3). El código se escribe solo.

CSS Grid Layout en tiempo récord

        
A diferencia de Flexbox, Grid maqueta en dos dimensiones a la vez: filas y columnas, como una cuadrícula hecha a la medida de tu sitio.

      

    


    
paso 1 Columnas, filas y líneas

    

      
Crea la carpeta repaso-grid, un contenedor con la clase grid-layout y diez cajas (c1, c2…). display: grid solo no cambia nada: hay que decir cuántas columnas tiene con grid-template-columns.

      
Las columnas se separan con líneas numeradas: con 3 columnas hay 4 líneas. Con grid-column: 1 / 4 una caja va de la línea 1 a la 4, y 1 / span 2 significa "empieza en la 1 y ocupa 2 columnas".

    

    

      

      

        

          
.grid-layout10 cajas

          

        

        

      

    

    
TipEn las herramientas del navegador (inspeccionar elemento) puedes activar la superposición de grid para ver los números de cada línea.


    
paso 2 grid-template-areas

    

      
Lo más potente de Grid: dibujas el sitio con nombres. Cada fila del texto es una fila del grid, y repetir un nombre hace que la caja ocupe esas columnas. Luego cada hijo dice a qué área pertenece con grid-area (sin comillas).

Resumen: ¿cuál uso?

        
No compiten: se combinan. Puedes usar Grid para la estructura general, Flexbox dentro de cada parte e incluso float donde haga falta.

      

    

    

      

        
Flexbox

        

        
    
          
  • Una dimensión: fila o columna.
    • 
          
  • Ideal para menús, barras y grupos de elementos.
    • 
          
  • display: flex, flex-flow, justify-content, align-items, align-content
    • 
          
  • En los hijos: order, flex-grow, flex-basis
    • 
        

      

      

        
CSS Grid

        

        
    
          
  • Dos dimensiones: filas y columnas.
    • 
          
  • Ideal para la estructura completa de una página.
    • 
          
  • display: grid, grid-template-columns, grid-template-rows, grid-template-areas
    • 
          
  • En los hijos: grid-column, grid-row, grid-area
    •
