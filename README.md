# CSS, Flexbox y Grid · Curso básico

Página web con las instrucciones del curso básico de **CSS, Flexbox y CSS Grid Layout** de Víctor Robles, explicadas paso a paso y con ejemplos interactivos.

Elaborado por **María Celeste Guevara**.

## Contenido

1. **Antes de empezar**: qué necesitas y para quién es el curso.
2. **CSS**: estructura HTML del proyecto, formas de añadir CSS, selectores, el sitio construido regla por regla, y `padding` con `calc()`.
3. **Flexbox**: `display: flex`, dirección, `wrap`, alineación, `order`, `flex-grow` y `flex-basis`, con un laboratorio interactivo.
4. **CSS Grid**: columnas, filas, líneas, `grid-column`, `grid-row` y `grid-template-areas`.
5. **Resumen**: cuándo usar Flexbox y cuándo Grid.

## Tecnologías

HTML, CSS y JavaScript, sin librerías ni frameworks. Todo vive en `index.html`.

## Ver en local

Abre `index.html` en el navegador.

El sitio se publica en [Vercel](https://vercel.com) importando este repositorio de GitHub. No necesita configuración: Vercel sirve el `index.html` de la raíz.
